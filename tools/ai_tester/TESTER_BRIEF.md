## 무엇을 하나
마구매니저(KBO 야구 매니저 카드 게임, 옛 모바일 게임을 개인용으로 되살린 것)를 처음 시작하는 플레이어로서 직접 해 봅니다.
보고 누르며 운영하고, 무엇이 좋고 무엇이 불편한지 리뷰를 씁니다. 리뷰를 읽는 사람은 이 게임을 되살리는 개발자(게임 주인)입니다.

게임 주인이 정한 운영 방식(원문: "ai테스터계정은 랜덤하게 구단을 생성한 다음, 해당 구단의 특정 단일년도 세트덱을 만들고 특강, 트레이닝, 코칭스태프 등등 다 직접 운영하고 진행하는걸로 해줘."):
1. 구단 만들기 화면에 나오는 구단 중 하나를 **무작위로** 고릅니다. PowerShell `Get-Random`으로 번호를 뽑고, 뽑은 값과 목록을 notes.md에 적습니다.
2. **가장 큰 목표: 챔피언스 리그에 최대한 빨리 들어가기.** (게임 주인 원문 11-09: "쿠폰 5개 지금 다 써도 돼. 그걸 사용해서 최대한 빠르게 챔피언스 리그 입성하는 것을 목표로 두고 합시다.") 리그 등급과 승격 규칙은 게임 안에서 알아냅니다.
3. 덱은 그 구단의 **한 해(단일 연도) 선수들로 만든 세트덱**을 기본으로 합니다. 연도는 게임 안에서 보고 정하고 이유를 적습니다. 세트덱 효과(팀컬러)는 게임 안의 설명으로 알아냅니다. 세트덱이 챔피언스 목표에 방해되면 바꾸고 이유를 적습니다.
4. 라인업, 상점(카드팩), 선수 조합, 특강(특별수강), 트레이닝, 코칭스태프, 계약 관리, 리그 경기 관람과 결과 확인까지 **직접** 운영합니다.
5. 쿠폰은 로비 COUPON 버튼에서 다섯 개를 씁니다(계정당 한 번): MAGU2026, TRAIN2026, START2026, SUPPORT2026, COACH2026. TESTGIFT·TESTTRAIN은 쓰지 않습니다. 받은 것을 notes.md에 적습니다.
6. MP나 아이템을 쓰는 결정(어떤 카드팩·코치팩을 몇 개 살지, 무엇을 조합할지, 누구를 특강·트레이닝할지)마다 **왜 그렇게 정했는지**를 notes.md에 한두 줄로 적습니다. 게임 주인은 나중에 이 기록을 보고 AI가 운영을 어떻게 이해했는지 봅니다. 효율적인 방법을 미리 알 필요는 없고, 화면과 설명만으로 판단이 어려웠던 곳은 그것대로 리뷰 거리입니다.

## 손과 눈 (도구)
게임은 이 PC의 창(1560×720, 휴대폰 비율)으로 떠 있습니다. 마우스로 누르는 것이 휴대폰에서 손가락으로 누르는 것과 같습니다.
`C:\Ma9MProject\tools\ai_tester\ma9m_eye.exe` 를 PowerShell에서 씁니다. 좌표는 모두 화면 캡처(가로 960) 위의 좌표입니다.

| 명령 | 뜻 |
|---|---|
| `ma9m_eye shot <png>` | 게임 화면 캡처(960×443). Read 도구로 그림을 봅니다 |
| `ma9m_eye zoom <png> x y w h` | 그 영역을 2배로 캡처(작은 글씨 읽기) |
| `ma9m_eye click x y` | 한 번 누르기 |
| `ma9m_eye dbl x y` | 두 번 빠르게 누르기(더블탭) |
| `ma9m_eye hold x y [ms]` | 꾹 누르기(기본 1.2초, 게임은 0.7초부터 꾹 누름으로 봄) |
| `ma9m_eye drag x1 y1 x2 y2 [ms]` | 끌기·밀기(목록 넘기기) |
| `ma9m_eye wheel x y n` | 마우스 휠(+위, -아래), 안 먹으면 drag로 |
| `ma9m_eye type 글자` | 글자 입력(한글 됨). 입력 칸을 먼저 누르세요 |
| `ma9m_eye key enter/esc/back` | 키. esc는 휴대폰 뒤로 가기와 같을 수 있음 |

- 캡처는 `C:\Ma9MProject\tools\ai_tester\runs\1109\shots\` 에 `001_로그인.png`처럼 번호를 붙여 저장합니다.
- 어떤 명령이든 끝에 `--shot <png>`를 붙이면 1.5초 기다린 뒤 캡처합니다(예: `ma9m_eye click 480 415 --shot shots\012_로비.png`). 누른 뒤에는 이렇게 결과를 확인합니다.
- 몇 분 이상 기다릴 때(리그 경기는 20분마다, 특강·트레이닝은 시간이 걸림)는 Monitor 도구나 run_in_background 명령을 씁니다. 짧은 sleep을 이어 붙이는 것은 막혀 있습니다. 기다리는 동안 할 일이 있으면 먼저 합니다.
- 게임이 멈추거나 꺼졌으면: `powershell -File C:\Ma9MProject\tools\ai_tester\start_game.ps1 -Restart` (autotest2 계정으로 다시 로그인). 재시작은 버그로 적습니다.
