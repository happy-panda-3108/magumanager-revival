## 1. 흐름

```
전력강화 > FA 시장 → 카드 고르기 → [FA 영입]
  → 협상 화면 (에이전트와 대화, 선수 만족도 게이지)
       ├ 게이지 100 → 에이전트 "좋습니다. 6시즌(15일), 1,650만 MP에 서명하죠." → [서명하기]
       ├ 4번 주고받아도 100이 안 되면 → 에이전트의 마지막 제안 → [받아들이겠습니다] / [그만두겠습니다]
       ├ 게이지 0 아래 → 결렬 (이번 시즌에는 이 선수와 다시 협상 못 함)
       └ [정가로 바로 계약] (언제든: 정가, 4시즌(10일), 컨디션 그대로)
  → [서명하기] → 서버가 영입(MP·카드·계약) → 협상 화면 닫힘
  → 계약서 서명 연출 → 입단식 (엔진 세션, Ma9MFaCeremony)
  → 서버의 결과 창(남은 MP, 크게 만족이면 그 줄) → FA 시장 다시 그림
```

서명을 먼저 하고 장면을 뒤에 보여 준다. MP가 모자라거나 자리가 없어 영입이 안 되면 장면 없이 협상 화면에 이유가 나온다(실패한 영입이 "계약 완료"로 보이지 않게).

재계약도 같은 화면이다. FA 카드의 계약이 2일 이하로 남았거나 끝나면, 계약관리의 [연장] → 보너스 5점 고르기 → [확인]이 협상을 연다(선수 정보 창의 계약 탭도 같다). 합의하면 그 계약금·날수로 연장(EXTEND)이 가고, 성공하면 재계약서 장면 → 목록 갱신. 1군 일괄 연장에서 FA는 빠진다("FA n명은 에이전트와 한 명씩 재계약을 협상하세요"). 옛 앱(1.0.54)은 지금처럼 정가·14일.

미리 연장(사용자 11-17 11:5x "미리 연장하는 기능도 만듭시다. 기존 FA계약 시스템 사용에 대화만 조금 수정하면 될 것 같음"; 서버 FaNegotiation.Early, 12:0x):
- 남은 날이 2일을 넘으면 협상 없이 에이전트가 바로 제안한다. 계약금은 계약관리 값(웃돈 × (5 + 남은 날 − 2) / 5), 기간은 정가 계약과 같은 4시즌(10일).
- 화면은 합의 화면으로 바로 열린다: "아직 계약이 n일 남았는데 벌써 연장하시겠다고요? 미리 하시면 웃돈이 붙습니다." → [재계약하기].
- 그 시즌 결렬된 선수는 안 됨. 계약 99일이면 안 됨.

사용자 11:5x에 정한 것: 결렬된 선수는 그 시즌만 막히고 다음 시즌 명단에서 다시 만나면 영입할 수 있다(지금 그대로). 1군에 넣지 않았을 때의 벌(태업 등)은 없다.

## 2. 협상 규칙 (서버 FaNegotiation)

### 에이전트 성향 (선수마다 하나: (선수번호×31 + 연도) & 3 — 같은 선수는 늘 같은 성향)

| 성향 | 좋아하는 것 | 아닌 성향일 때 |
|---|---|---|
| 돈을 중시 | 계약금 올리기 +30 / 깎기 −25 | 올리기 +20 / 깎기 −15 |
| 우승을 원함 | "우승 도전": 10 + 25×강도 (강도 = 0.6×리그 단계 + 0.4×순위) | 5 + 5×강도 |
| 주전을 원함 | "주전 보장": +35 | +10 |
| 옛 동료를 아낌 | "옛 동료": 1군에 같은 해·같은 구단 동료 6×명(최대 30, 0명이면 −5) | 2×명(최대 10) |

- 긴 계약: 6시즌 → 8시즌(20일), 게이지 +15 (성향 무관).
- 조건 카드는 아직 안 쓴 넷 중 앞의 둘이 차례마다 나온다(주전 → 우승 → 동료 → 긴 계약 순). 한 번 쓰면 끝.

### 게이지와 차례

- 시작: 영입 40, 재계약 55(함께 뛴 정).
- 첫 요구 계약금: 정가의 110%, 돈 성향 115%.
- 고르기 넷: [계약금 올리기 +10%p] · 조건 카드 둘 · [계약금 깎기 −10%p]. 계약금은 정가의 75%~130% 안이고, 130%에서 더 올리면 +5뿐이다.
- 최대 4차례. 4번째에도 100이 안 되면 마지막 제안: 모자란 10점마다 +5%p(130% 한도), [받아들이겠습니다]면 합의.
- 게이지 0 아래 = 결렬. (user, 카드, 시즌)을 표 fa_nego_fail에 적고 그 시즌에는 다시 협상하지 않는다. 시장 명단에는 남는다(정할 것: 명단에서 뺄지).
- 크게 만족: 합의 순간 게이지가 110 이상이면, 서명(재계약) 때부터 24시간 동안 컨디션 최상으로 뛴다. 회복제가 아니라서 선수관리 회복제 5칸은 그대로 다른 선수에게 쓸 수 있다. 서버는 표 fa_top(user, 카드, until)에 적고, Condition.Level이 그 시간 안이면 최상(0)을 돌려준다. 24시간 뒤에는 평소 컨디션으로 돌아간다.
  - 성향에 맞는 큰 카드를 마지막에 내야 넘는다. 예: 주전 성향은 올리기 → 올리기 → 우승 → 주전(40→60→80→85→120). 돈 성향은 주전 → 우승 → 올리기 → 올리기.
- 협상은 10분 동안 메모리에 둔다. 합의도 10분 안에 서명(재계약은 EXTEND)해야 한다.
- 약속(주전 보장)을 어긴 벌은 첫 판에 없다(정할 것).

### 우리 게임의 계약 말

- 기간은 "시즌"으로 말한다. 1시즌 = 리그 한 바퀴 2.5일. 정가 바로 4시즌 = 10일, 협상 6시즌 = 15일, 긴 계약 8시즌 = 20일.
- 에이전트 말 예: "심정수 선수는 몸값이 있습니다. 6시즌 보장, 계약금 1,725만 MP는 받아야겠습니다." / "주전 보장이라면 이야기가 달라지죠." / "비기너 10위에서 우승이요? 글쎄요."

## 3. 서버

- `FaNegotiation.cs`: 협상 상태, 결렬 기록(fa_nego_fail), 합의(Deal: 카드, 계약금, 날수, 크게 만족, 10분).
- 요청: REQ_SCENE_TUTORIAL "ma9m:v2:fan:<idx>:<동작>"(AdviceHandlers.TryHandle). 동작: start · c0~c3 · quick · accept · quit · sign.
- 답: PKS_SC_POPUP. 쓰는 번호를 확인함(0·1·2·9·10·11·20·21 사용 중).
  - 30 = 차례: [제목, 에이전트 말, 게이지, 지금 조건, 고르기1~4, "에이전트 이름 · 성향", 남은 대화, 카드 번호, turn/last, 게이지 변화, 재계약 0/1]
  - 31 = 합의: [제목, 말, 카드 번호, 선수 이름, 원래 구단, 시즌, 날수, 계약금, 정가, 게이지, 크게 만족 0/1, 재계약 0/1, 우리 구단, 엠블럼]
  - 32 = 로비 소식 띠: [소식1, 소식2, …] (NewsFeed)
  - 33 = 끝: [제목, 글, 성공 0/1] (서명 결과, 거절, 결렬)
- 영입: sign → `FaMarket.SignWith(user, idx, 계약금, 날수)`. 크게 만족이면 fa_top에 24시간(`FaNegotiation.TopAt`을 `Condition.Level`이 부름).

- 앱 구별: ClientVersion의 "ma9m-fan1"(협상), "ma9m-news1"(소식 띠). 없으면 지금 흐름 그대로.
